## Getting Started

```bash
npm install

npm run dev

npm run build
```

## Features

* User authentication: **Login, Logout, Register**
* Profile: **View, Edit, Update**
* Posts: **Add, Edit, Delete, View feed**
* Search: **Find any post quickly**
* Single Post View:

  * Open post with full details
  * **Comment system (highlighted feature)**
  * See other user profiles directly from post page (**clickable DP**)
  * View their **followers, following, posts**
  * Open posts from user profiles
  * **Follow / Unfollow** users
* **Pagination (highlighted)**: Navigate Next / Prev pages
* Engagement: Public **comments & reactions**
* UI: **Notification div (toastify)** for instant feedback
